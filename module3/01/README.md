# Программа создания копий файлов

Программа для создания копий файлов через каналы(именнованый/неименованный) с использованием родительского и дочернего процессов.

## Команды Make

```bash
make          # Сборка программы
make test     # Запуск всех тестов
make clean    # Очистка (удаление программы, копий и временных файлов)
